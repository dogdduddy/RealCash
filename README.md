# RealCash

> 카드로 내지만, 지갑은 현금처럼.

디지털 결제(삼성페이·애플페이·카드)는 그대로 쓰면서, 돈을 **보고 · 꺼내고 · 거슬러 받는 감각** 만 현금처럼 되살려 지출을 줄이는 앱.
[HardPay](https://github.com/dogdduddy/HardPay) 사이드 프로젝트의 후속으로, Android + iOS 를 함께 목표로 한다.

## 상태

기획 단계. 아직 코드 없음.

## 핵심 아이디어 (요약)

1. **결제 순간에 앱을 열지 않는다.** 개입은 결제 전(지폐 꺼내기)과 후(자동 정산)로 옮긴다.
2. **지폐는 개체다.** 처음 받은 권종 조합이 그대로 유지되고, 환전은 사용자가 직접 한다.
3. **정산은 자동, 결정은 수동.** 결제 알림을 읽어 거스름돈까지 계산하고, 무엇을 꺼낼지는 사용자가 정한다.
