# 04. 홈·지갑 인터랙션 재설계 (2026-11-04 실기기 피드백)

> 상태: 설계 확정 전(피드백 반영 초안). 실현 가능성 평가와 구현 분해를 담는다. 근거 피드백: "처음 사용 시 뭘 어떻게 할지 감이 안 잡힌다. 화면에 정보가 너무 많다."

## 1. 목표 플로우

```
[홈] 기간 + 남은 금액 (큰 숫자) + 접힌 지갑(두께 = 지폐량)
  └─ 지갑 탭 → 지갑 열리는 전환 애니메이션
[열린 지갑] 위: 접시(꺼낸 돈 두는 곳) + 계산 버튼 / 아래 3/5: 위에서 내려다본 열린 지갑
  · 지폐: 비싼 권종이 왼쪽, 사이 여백, 스와이프하면 흔들림
  · 롱프레스 → 집힘 → 접시에 놓으면 가로로 눕고, 아무 데나 놓으면 지갑으로 복귀
  · 동전: 지갑 오른쪽에 널브러짐, 놓은 자리에 그대로, 화면 재진입마다 다시 흩뿌려짐
  · 계산 버튼 → 팝업: "실제 결제하면 가계부에 자동으로 들어가요. 안 되면 설정에서 알림 권한을 켜 주세요."
```

도메인 매핑: 접시 = `Hand`(IN_HAND), 지갑 = IN_WALLET, 계산 버튼은 상태를 바꾸지 않는 안내(정산은 알림 인테이크 또는 직접 기록).

## 2. 실현 가능성 평가

| 요소 | 판단 | 구현 방식 | 리스크 |
|---|---|---|---|
| 홈: 기간·남은 금액, 큰 숫자, 줄 배치 | 쉬움 | 기존 `BudgetPeriods`·`WalletState.balance`. 글자 2줄("이번 달" / "₩442,000 남음") | 없음 |
| 접힌 지갑, 두께 = 지폐량 | 쉬움 | 접힌 지갑 이미지 + 장수에 비례한 옆면 레이어(최대 ~24dp). 이미지 1장 필요 | 이미지 품질 |
| 지갑 열기 전환 | 중간 | `graphicsLayer(rotationX, cameraDistance)`로 덮개가 젖혀지며 열린 지갑 화면으로 크로스페이드. 300~450ms | iOS에서 큰 비트맵 회전 성능 → 레이어 캐시 |
| 열린 지갑 위에서 내려다본 배치, 세로 3/5 | 쉬움 | 열린 지갑 이미지(투명 PNG) 1장 + 그 위에 지폐를 포켓 안쪽에 배치, 포켓 상단 가장자리로 clip | 이미지 1장 필요 |
| 지폐 배치: 비싼 것 왼쪽, 여백 | 쉬움 | 권종별 묶음을 왼→오 배치, 묶음 안은 3~8dp 간격 팬(fan). 장수 많으면 간격 축소 | 30장 넘으면 집기 어려움 → 앞장만 집히게 |
| 스와이프하면 지폐 흔들림 | 중간 | 가로 드래그 속도를 각 지폐의 `Animatable` 스프링에 지연(stagger)으로 주입 → 기울기·x 오프셋. HardPay의 graphicsLayer 지연 읽기 패턴 유지 | 지폐 30장 × 스프링: 60fps 가능(이미 비슷한 패턴 검증) |
| 롱프레스 집기 → 따라옴 → 접시/복귀 | 쉬움 | `detectDragGesturesAfterLongPress` + 기존 드래그 고스트. 접시 영역 밖에서 놓으면 원래 슬롯으로 스프링 복귀 | 스와이프(즉시 드래그)와 롱프레스 드래그 구분 — 제스처가 서로 배타라 충돌 없음 |
| 접시 위에 가로로 눕기 | 쉬움 | 놓는 순간 rotationZ 90° → 0° 스프링, 접시 안에서 왼쪽부터 쌓임 | 없음 |
| 동전 흩뿌리기, 놓은 자리 유지, 재진입 시 초기화 | 쉬움 | 진입 시 시드 난수로 위치·회전 생성 → 떨어지는 스프링. 놓은 위치는 화면 수명 동안만 기억 | 없음 |
| 계산 버튼 팝업 | 쉬움 | AlertDialog, 권한 상태(Android)는 플랫폼 디버그 진입점 재사용 | 없음 |
| 햅틱 | 쉬움 | 기존 `Haptics` 인터페이스 확장: `tick`(스와이프 중 지폐 스칠 때), `pickUp`, `drop`, `snap`(지갑 열고 닫기). Android `VibrationEffect` predefined, iOS `UIImpactFeedbackGenerator`/`UISelectionFeedbackGenerator` | 없음 |
| 소리 | 중간 | `SoundPlayer` expect/actual: Android `SoundPool`, iOS `AVAudioPlayer`(ambient 카테고리 → 무음 스위치 존중), 데스크톱 `javax.sound`. 효과음 5종(지갑 열기/닫기, 지폐 스침, 집기, 놓기, 동전 소리) | **효과음 파일 출처**: GPT 이미지 파이프라인으로는 못 만든다. 1차는 합성 플레이스홀더(numpy), 최종은 CC0 효과음 또는 직접 녹음 |

결론: 전부 가능. 가장 큰 작업은 "스와이프 흔들림 + 롱프레스 집기"의 물리감이고, 나머지는 기존 부품 조합이다.

## 3. 홈에서 빠지는 정보의 행선지

| 기존 홈 요소 | 새 위치 |
|---|---|
| 손에 든 돈 카드 | 열린 지갑 화면의 접시 |
| 확인 필요 결제 배너 | 홈 지갑 위 작은 배지("확인 1") → 탭하면 확인 시트 |
| 권종별 스택 그리드 | 열린 지갑 화면 |
| 용돈 받기 FAB | 홈: 지갑이 비었을 때만 큰 버튼. 평소엔 오른쪽 위 메뉴 |
| 환전, 가계부, 설정, 직접 기록 | 오른쪽 위 메뉴(가계부·설정은 하단 탭 유지 여부 결정 필요) |

## 4. 필요한 에셋 (이미지 파이프라인)

1. `wallet.closed.a` — 접힌 지갑, 위에서 내려다본 모습, 가죽 질감, 투명 배경. 옆면(두께)은 코드로 그리므로 얇은 상태로.
2. `wallet.open.a` — 펼친 지갑, 위에서 내려다본 모습, 지폐 포켓이 아래쪽, 비어 있음, 투명 배경. 포켓 안쪽 가장자리 좌표를 검수 때 기록해 코드 상수로.
3. `tray.a` — 접시(또는 카운터 트레이), 위에서 내려다본 모습, 투명 배경.
4. 효과음 5종 — 파이프라인 밖(아래 6).

## 6. 효과음 조달

- 1차: `tools/sfx/`에 numpy 합성 스크립트로 플레이스홀더 5종(짧은 노이즈 버스트·클릭·금속 울림)을 만들어 `assets/sfx/` 에 둔다. 리뷰·튜닝은 실기기에서.
- 최종: CC0 효과음(freesound 등)을 사람이 골라 교체하거나 직접 녹음. 출처는 `assets/LOG.md` 에 기록.

## 7. 결정 (2026-11-04 사용자)

1. 기간 기본값 **이번 달**(MONTHLY, 1일 시작). 설정에서 주간으로 바꿀 수 있다. `AppSettings` 기본값 변경 완료.
2. **하단 탭 제거.** 가계부·설정·환전·직접 기록·용돈 받기는 홈 오른쪽 위 메뉴(및 열린 지갑 화면의 보조 버튼)로.
3. 효과음은 **CC0**(1차 후보 Kenney 오디오 팩, 출처는 assets/LOG.md 에 기록). 플레이스홀더 합성은 생략.

## 8. 결정 (2026-11-05 사용자) — 지갑 시점·재질 변경

1. 지갑은 **검은 크로스그레인(사피아노) 가죽 반지갑**. 장지갑 아님. 홈의 닫힌 지갑은 제품 사진처럼 3/4 시점, 전체가 잘리지 않게.
2. **지폐 수에 따른 두께 표현은 없앤다.** 지갑 위치·크기는 항상 같다.
3. 열린 화면은 **반지갑을 펼쳐 세로로 들고 지폐 칸을 양손으로 벌려 위에서 들여다보는 1인칭 시점**. 손은 그리지 않고 지갑만. 세로로 들어야 지폐 뭉치가 한눈에 들어온다(스케치 `assets/reference/wallet-open-sketch.jpg`: 위 네모 = 접시, 아래 흰 윤곽 = 벌어진 칸, 색선 = 지폐).
4. 칸 안의 지폐는 **비스듬히 내려다봐서 앞면 윗부분(약 35%)이 보이는** 쪽(b). 집으면 앞면 전체, 접시에서는 눕는다.
5. 동전은 지갑 바깥 **바닥**에 널브러진다. 처음엔 오른쪽 여백에만, 집어서 왼쪽 바닥에도 놓을 수 있다.
6. 자산: `wallet.closed.b`, `wallet.open.b` 로 교체(의뢰 12·13). 지폐·동전·접시 그림은 그대로. 검수 때 `wallet.open.b.opening` (칸 입구 비율 좌표)을 manifest 에 기록한다. UI 의뢰: 10 ui.home-wallet-v3, 11 ui.wallet-open-v3.
7. 미결: 집었을 때 지폐 크기(실물 길이 vs 접시 높이에 맞춰 축소)는 기기 테스트 뒤 결정.
