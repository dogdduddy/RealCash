[목적] 열린 지갑의 스와이프 흔들림이 굉장히 어색하다(사용자 기기 테스트 2026-11-05). 지금은 가로 드래그 속도에 따라 칸 안의 모든 지폐가 윗모서리(transformOrigin 0,0)를 축으로 rotationZ ±12°·translationX ±6dp 로 동시에 흔들려, 세워 꽂힌 종이가 아니라 평평한 조각들이 일제히 기우는 것처럼 보인다. 꽂힌 지폐를 손가락으로 훑는 물리로 바꾼다: 손가락이 닿은 장만 칸 바닥을 축으로 진행 방향으로 밀렸다가 튕겨 돌아온다. 위에서 보면 노출 띠가 옆으로 밀리고(translationX) 기울기가 바뀌어(rotationX) 보이는 면이 살짝 넓어지거나 좁아진다. Z축 회전은 없다. 집기는 지금 그대로 좋다고 했으니 건드리지 않는다.

[요청] 열린 지갑 흔들림 v2 — 손가락이 지나는 지폐만 밀렸다 튕기기
1. rotationZ 흔들림을 없앤다. 지폐 하나의 흔들림 상태는 displacementDp(부호 있음) 하나다. graphicsLayer 에서 translationX = displacement, 안쪽 레이어의 rotationX = 60 - displacement × 1.2 (±12° 한도) 로 지연 읽기한다. 오른쪽으로 밀리면 더 눕고(면이 넓어 보임), 왼쪽이면 더 선다.
2. 밀기: 손가락이 누른 채 가로로 움직일 때, 진행 방향 기준으로 손가락이 닿은 장(노출 띠 또는 뒤 장의 가장자리 띠)은 손가락에 붙어 밀린다: displacement = 손가락 x − 띠의 진행 방향 쪽 가장자리, 한도는 min(10dp, 이웃 띠까지 거리 − 1dp). 손가락이 한도를 넘어 지나가면 그 장은 놓여서 0 으로 스프링 복귀(dampingRatio 0.35, stiffness 420 — 한 번 살짝 오버슈트). 즉 훑으면 한 장씩 차례로 밀렸다 튕긴다.
3. 이웃 전파: 한 장이 놓이는 순간 바로 옆 장(같은 묶음이든 이웃 묶음이든)에 그 장 최대 변위의 1/2, 그 다음 장에 1/4 를 20ms·40ms 뒤에 짧게 주고 같은 스프링으로 복귀. 손가락에서 먼 장은 움직이지 않는다.
4. 햅틱 틱은 지금처럼 띠를 가로지를 때 장당 1회. 손을 떼면 밀려 있던 장은 모두 복귀.
5. 성능 조건 유지: 스프링 프레임이 지폐 컴포지션을 다시 일으키지 않는다(기존 WalletOpenSwayTest 의 compositions 검사 유지, rotationZ 관련 단언은 새 모델로 바꾼다).
6. 테스트: (a) 순수 함수로 "손가락 위치·방향·띠 경계 → displacement 와 놓임 여부", "이웃 전파 1/2·1/4·지연", "displacement → rotationX 매핑·한도" 검증, (b) 30장 가로 훑기에서 틱 수 = 가로지른 띠 수, 리컴포지션 0 유지.
