[요청] 열린 지갑 화면 — 접시·지갑·지폐 팬·동전 흩뿌리기 정적 배치
1. 세로 구성: 상단 접시 영역(화면 높이의 약 22%, 트레이 이미지 가로 92%), 그 오른쪽 아래에 작은 "계산" 버튼. 하단 3/5 에 지갑 이미지(세로 60%, 가로는 비율대로, 가운데 정렬). 상단 왼쪽에 뒤로 화살표, 상단 중앙에 "손에 ₩x · 지갑 ₩y" 한 줄.
2. 지폐 배치(포켓 안): 지갑 안 IN_WALLET 지폐를 권종 내림차순(오만원이 가장 왼쪽)으로 묶어 포켓 안쪽 영역에 세로로 세워 꽂는다. 각 지폐는 BillFace 를 rotationZ 90°로 세운 모습(지폐 긴 변이 세로). 같은 권종은 x 방향으로 겹치며 팬(fan): 간격 = min(10dp, 가용폭/장수), 뒷장일수록 살짝 어둡게. 권종 묶음 사이 여백 ≥ 14dp(집기 쉽게). 포켓 입구(topFraction) 위로 지폐의 윗부분 약 28% 가 보이고 아래는 포켓에 가려진다(지폐를 포켓 안쪽 영역 뒤 레이어로, 입구 위로는 지갑 이미지 위에 그려지도록 두 레이어로 나누어 그린다: 지갑 이미지 아래에 지폐 전체, 지갑 이미지 중 포켓 앞면 부분을 위에 덮어 clip). 장수가 많아 안 들어가면 간격을 3dp 까지 줄이고 그래도 넘치면 뒷장은 숨기고 묶음 위 작은 배지 "×N".
3. 접시 위: IN_HAND 지폐를 가로로 눕혀(회전 0°) 트레이 바닥 영역 왼쪽부터 6dp 간격으로 겹쳐 놓고, 동전은 그 오른쪽에 둔다. 손에 든 합계를 접시 오른쪽 위에 작게.
4. 동전: 지갑 오른쪽 옆(지갑 이미지 오른쪽 바깥 폭 약 18%)에 IN_WALLET 동전을 흩뿌린다. CoinScatter(seed, count, 영역) 가 겹치지 않게(최소 거리 = 지름의 0.9) 위치·회전을 만든다. 화면에 들어올 때마다 새 seed 로 다시 뿌리고, 위에서 떨어지는 스프링 애니메이션(지연 30ms 간격). 동전 지름은 500 > 100 > 50 > 10 비율 유지, 500원 = 34dp.
5. 이번 의뢰의 인터랙션(임시): 지폐·동전 탭 → 접시로 이동(moveToHand 에 해당하는 임시 선택 상태를 모델에 두고 "손에 들기" 확정은 접시의 작은 버튼 "확정"으로 1회 호출, 또는 화면을 나갈 때 자동 확정). 접시 위 지폐·동전 탭 → 지갑으로 복귀. 물리는 다음 의뢰.
6. "계산" 버튼 → AlertDialog: 제목 "결제는 평소처럼", 본문 "삼성페이·토스·카드로 결제하면 알림을 읽어 자동으로 가계부에 들어가요. 안 들어오면 설정 → 알림 접근을 켜 주세요. 직접 기록도 할 수 있어요.", 버튼 "직접 기록"(기존 ManualPaymentSheet) / "닫기".
7. 다크 테마 확인. 스크린샷: (t) 지갑에 네 권종+동전, 접시 비어 있음 (u) 접시에 10000+5000 과 500원 하나 (v) 계산 팝업.
