1. 지갑 그림 Res.drawable.wallet_open (교체된 새 그림, 세로가 긴 비율)을 접시 아래 가운데에 화면 세로의 3/5 높이로, 잘리지 않고 전체가 보이게 둔다. 칸 입구(렌즈) 영역은 assets/manifest.json 의 wallet.open.b.opening (그림 기준 top/left/right/bottom 비율) 을 상수로 쓴다. 기존 pocket(0.405 등) 상수는 버린다.
2. 지폐는 칸 안에 세워져 있고 위에서 비스듬히 내려다본 모습으로 그린다: 각 지폐의 앞면 윗부분 약 35% 가 보이고 나머지는 칸 벽에 가려진다(clip). 원근은 graphicsLayer rotationX(약 55~65°, cameraDistance 를 충분히 크게) 로 표현하되 액면 숫자·"만원" 글자가 읽히는 방향. 권종 묶음은 비싼 것부터 왼쪽→오른쪽(오만원·만원·오천원·천원), 묶음 사이 간격, 같은 묶음은 지금처럼 장수 가중 팬(30장도 들어가게). 지폐의 실제 비율(오만원이 제일 길다)은 유지.
3. 동전: 화면에 들어올 때마다 지갑 오른쪽 바닥(지갑과 화면 가장자리 사이 여백)에 새로 흩뿌린다. 길게 눌러 집어 바닥 어디에든(지갑 왼쪽 여백 포함, 접시·지갑 그림 밖) 놓으면 그 자리에 머문다(이 화면을 보는 동안). 접시에 놓으면 손으로. 지갑 그림 위에 놓으면 원래 자리로 스프링 복귀. 동전이 바닥에 겹치지 않게 배치.
4. 스와이프 흔들림·롱프레스 집기·접시 놓기·복귀·300ms 저장·제스처 연속성(09 결과)을 모두 유지한다. 집으면 지폐 앞면 전체가 보이고(지금 크기 그대로), 접시에서는 눕는다. 집기 히트 영역은 칸 안에서 보이는 윗부분.
5. 가로 모드는 접시 왼쪽, 지갑 오른쪽 배치를 유지한다.
