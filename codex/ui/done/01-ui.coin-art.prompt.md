[목적] 검수를 통과한 실물풍 동전 이미지 4종(500·100·50·10원)을 지폐와 같은 방식으로 화면에 연결한다. 지폐는 이미 ResourceMoneyArt 로 연결돼 있고(ui.money-art 머지됨), 동전만 Canvas 플레이스홀더로 남아 있다.

[화면·파일] shared/ui 안에서만 작업한다. money/MoneyArt.kt(ResourceMoneyArt), money/MoneyFaces.kt(CoinFace, CoinStack, UnitChip, relativeSize 의 동전 분기), 꺼내기 화면의 드래그 고스트(takeout/TakeOutScreen.kt), 스크린샷 테스트(jvmTest screenshot/ScreenshotTest.kt). 리소스 접근자는 com.jim.realcash.ui.resources.Res.drawable.coin_c500, coin_c100, coin_c50, coin_c10 (512x512 투명 PNG, 동전은 정원이고 캔버스 가득 참).

[요청] 실물풍 동전 이미지 4종을 지갑·꺼내기·환전 화면에 연결
1. ResourceMoneyArt.painter 가 C500/C100/C50/C10 에 대해 painterResource(Res.drawable.coin_cNNN) 을 돌려주게 한다.
2. CoinFace 는 painter 가 있으면 이미지를 그린다: ContentScale.Fit, CircleShape clip, 지폐보다 조금 강한 그림자(동전은 두께가 있다). 플레이스홀더는 painter 가 null 일 때만.
3. 실물 지름 비율을 relativeSize 에 반영한다: 500원 26.5mm, 100원 24.0mm, 50원 21.6mm, 10원 18.0mm (500원 = 1.0 기준으로 0.906, 0.815, 0.679). 동전 스택은 지름이 실물처럼 조금씩 다르게 보여야 한다.
4. CoinStack 의 겹침 레이어(장수 표현)는 동전 이미지를 살짝 어둡게 해 아래로 2~3dp 씩 오프셋. 장수 배지 유지.
5. UnitChip 의 동전 썸네일은 이미지를 지름 20dp 로. 꺼내기 드래그 고스트도 동전 이미지(기울임은 동전에는 주지 않고 그림자만).
6. 다크 테마는 지폐와 같은 처리(알파 0.92 정도).
7. 스크린샷: 기존 b, c, h, i, j, m 장면에서 동전이 이미지로 보이게 하고, 새 장면 (o) 동전 4종이 모두 있는 지갑 홈(500×3, 100×4, 50×2, 10×5)을 추가한다.

[완료 기준] ./gradlew :shared:ui:jvmTest 통과(기존 73 + 추가). 스크린샷에서 동전 플레이스홀더(회색 원 + 숫자)가 보이지 않는다. 동전 지름이 500>100>50>10 순으로 다르다. 기존 드래그·칩·배지 테스트 그대로 통과.
