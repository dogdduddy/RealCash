[요청] 접시의 돈을 한 번에 지갑으로 되돌리는 버튼
1. WalletOpenModel 에 returnAll(): 접시(inHand)에 있는 모든 유닛을 setOnTray(id, false) 와 같은 경로로 지갑으로 돌린다(choices 에 전부 false, trayOrder 비움, 300ms 디바운스 저장 → 리포지토리 returnHand). 저장 중(submitting)이면 queuedChoices 에 쌓이는 기존 규칙을 그대로 탄다. Haptics.success() 1회.
2. 화면: "계산" 버튼 왼쪽에 FilledTonalButton "모두 넣기"(접시에 돈이 있을 때만 보이고, 집는 중·저장 중에는 비활성). 누르면 접시의 지폐·동전이 지갑 쪽으로 스르륵 사라지는 짧은 전환(각 유닛 alpha 1→0 + 지갑 방향으로 24dp 이동, 200ms, 순서대로 30ms 간격) 뒤 접시가 빈다. 전환은 리컴포지션을 유닛 수만큼 늘리지 않게 graphicsLayer 지연 읽기로.
3. 접시 안내 문구("돈을 길게 눌러 접시에 놓으세요")는 비워진 뒤 다시 보인다. 접시 동전 위치 기억(trayCoins)도 비운다.
4. 테스트: (a) 모델 — 접시에 지폐 2·동전 1 이 있을 때 returnAll() 뒤 300ms 지나면 activeHand == null, inWallet 에 전부 복귀, 원장 이벤트는 returnHand 1회. (b) 저장 중 returnAll() 이 들어와도 최종 activeHand == null. (c) 화면 — 버튼은 접시가 빌 때 보이지 않는다(세만틱스 조회).
