[요청] 용돈 받기 — 스텝퍼로 바꾼 개수가 곧 받을 금액이 되게
1. 스텝퍼(increment/decrement)로 개수를 바꾸면 금액(digits)이 개수의 합으로 따라가게 한다(edited = true). 금액 필드에는 합이 표시된다. 금액을 직접 타이핑하면 지금처럼 개수가 스타일 제안으로 다시 채워진다(edited = false). 스타일 칩도 지금처럼.
2. 유효 조건: 합 > 0 이고 모든 개수 ≥ 0 이면 유효. 합과 금액이 다를 수 있는 상태가 없어지므로 showSumError 는 "금액을 타이핑했는데 제안이 비어 있는 경우(현금으로 표현 불가)"에만 쓴다. 합계 줄은 빨간색 대신 보통 색으로 "합계 ₩…" 을 보여 준다.
3. 저장(submit)은 split() 그대로(개수 구성 그대로) receiveAllowance 에 넘긴다. 완료 메시지의 금액은 합.
4. 테스트: (a) 금액 30,000 타이핑 → 제안 → 만원 +1 → digits == "40000", isValid, split 에 만원 4(또는 제안+1), (b) 만원 −1 로 0 이 되면 합도 줄고 합 0 이면 isValid == false, (c) 타이핑으로 다시 금액을 넣으면 edited == false 로 제안으로 복귀, (d) 모델 submit 이 스텝퍼 구성 그대로 저장.
