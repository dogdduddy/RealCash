# requires-review: ui.wallet-open-layout
[목적] 열린 지갑 화면에 "진짜 지폐를 만지는" 물리감을 넣는다. 스와이프하면 지폐가 흔들리고, 롱프레스로 집어 접시에 놓거나 놓친 자리에서 지갑으로 스르륵 돌아간다. docs/04 §1·§2.

[화면·파일] shared/ui/…/walletopen/ 만. HardPay 계보의 성능 패턴을 지킨다: 드래그 위치는 graphicsLayer 람다 안에서 지연 읽기, 컴포지션에서는 "집힌 id"와 "접시 위 여부"만 읽는다(기존 takeout/DragDropState.kt 참고).

[요청] 열린 지갑 물리 — 스와이프 흔들림, 롱프레스 집기, 접시 놓기와 복귀
1. 흔들림: 포켓 영역에서 가로 드래그(롱프레스 없이) 시 드래그 속도(px/s)를 각 지폐의 Animatable(기울기 -12°~12°, x 오프셋 ±6dp)에 스프링(dampingRatio 0.55, stiffness 180)으로 넣되, 손가락에서 먼 지폐일수록 15~40ms 지연을 둔다. 손을 떼면 모두 0으로 복귀. 손가락이 지폐 위를 지날 때마다 Haptics.tick()(새 메서드, 기본 구현은 tap 과 같게) 1회. 세로 스크롤과 충돌하지 않게 이 화면은 스크롤하지 않는다.
2. 집기: 지폐·동전 롱프레스(400ms) → Haptics.pickUp(), 해당 유닛이 1.08 배 커지고 그림자 깊어지며 손가락을 따라온다(기존 고스트 패턴). 포켓의 같은 묶음에서는 가장 앞장만 집힌다.
3. 놓기: 접시 바닥 영역 위에서 놓으면 지폐는 rotationZ 90°→0° 로 눕는 스프링과 함께 접시의 다음 자리로, 동전은 놓은 자리에 그대로. Haptics.success(). 접시 밖에서 놓으면 원래 슬롯으로 스프링 복귀(300ms) + Haptics.tap(). 접시 위 유닛을 집어 지갑 영역에 놓으면 지갑으로 복귀.
4. 확정: 접시 내용이 바뀌면 300ms 디바운스 후 WalletRepository 에 반영(moveToHand / returnHand → 접시 전체를 새 Hand 로; 비면 returnHand). 실패는 스낵바, 화면 상태는 리포지토리 상태를 정답으로 되돌린다.
5. 모든 애니메이션은 테스트 가능한 순수 상태(SwayState, PickState)로 분리하고, 스프링 목표값·지연 계산·놓기 판정을 단위 테스트한다. 드래그 제스처 자체는 스크린샷 (w) 집어서 접시 위에 떠 있는 상태로 확인한다.

[완료 기준] ./gradlew :shared:ui:jvmTest 통과. 스와이프 중 리컴포지션이 지폐 수에 비례해 늘지 않는다(람다 지연 읽기). 접시에 놓은 뒤 리포지토리의 activeHand 가 접시 내용과 같다.
