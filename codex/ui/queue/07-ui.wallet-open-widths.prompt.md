[목적] 열린 지갑 포켓의 지폐 치수를 실물대로 고친다. 지금은 모든 권종의 긴 변(L)을 같게 두고 폭을 비율로 나눠서 천원권이 가장 넓고 오만원권이 가장 좁다. 실물은 짧은 변(68mm)이 모두 같고 긴 변만 다르다(154/148/142/136mm). 세워서 꽂으면 폭이 같고, 오만원이 포켓 입구 위로 가장 많이 튀어나와야 한다. 또 노출 20%에서는 액면 숫자가 잘린다.

[요청] 포켓 지폐를 같은 폭·권종별 길이로, 숫자가 보이게, 장수에 비례한 자리 배분으로
1. 공통 폭 W: 가장 긴 오만원권 기준으로 L50 = (입구~포켓 바닥 − 0.06H) / 0.74 (노출 26%), W = L50 / (154/68). 나머지 권종은 Ld = W × (긴변d / 68). 모든 지폐 아랫변은 포켓 바닥에서 0.06H 위에 같은 높이로 놓인다 → 짧은 권종은 덜 튀어나온다(오만원 26%, 천원은 그보다 적게).
2. 묶음 피치: 전체 가용 = 포켓 폭 − W. 각 묶음에 (28dp 기본 + 팬에 필요한 폭(장수−1)×기본 8dp)의 비중으로 가용 폭을 배분하되 한 묶음의 최소 28dp 를 보장한다. 배분 후 팬 간격 = min(8dp, 배분폭/(장수−1)), 하한 3dp, 그 아래로만 배지.
3. 입구 위 노출 영역에 액면 숫자가 온전히 보이는지 스크린샷으로 확인한다(오만원 "50000", 천원 "1000"). 안 보이면 노출 비율을 0.30 까지 올려도 된다.
4. 테스트: 네 권종의 billWidth 가 전부 같다, billHeight 는 오만원 > 만원 > 오천원 > 천원, 아랫변 y 가 같다, 30장(2/10/8/10) 장면에서 만원·천원 묶음이 더 넓은 자리를 받고 배지 없이 3dp 이상 간격으로 전부 보이거나 하한에서만 배지가 생긴다.
5. 스크린샷 t/u/x 갱신.
