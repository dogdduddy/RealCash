[목적] 실기기 피드백 "처음 사용 시 뭘 어떻게 할지 감이 안 잡힌다, 정보가 너무 많다"를 해결한다. 홈을 "기간·남은 금액 + 접힌 지갑" 하나로 줄이고, 지갑을 탭하면 열리는 전환으로 열린 지갑 화면에 들어간다. 설계는 docs/04-wallet-interaction-redesign.md §1, §3, §7 을 따른다(하단 탭 제거, 월간 기본).

[화면·파일] shared/ui 안에서만 작업한다. wallet/WalletHomeScreen.kt·WalletHomeModel.kt(전면 교체), RealCashApp.kt(하단 탭 제거, 오른쪽 위 메뉴), AppState.kt(Screen.WalletOpen 추가 — 이번 작업에서는 열린 지갑 화면을 간단한 자리표시(접시 영역 + "T: wallet-open-layout" 텍스트 + 뒤로)만 두고, 실제 배치는 다음 의뢰 ui.wallet-open-layout 이 한다), components/, Strings.kt, 스크린샷 테스트. 리소스: com.jim.realcash.ui.resources.Res.drawable.wallet_closed (1024x540 투명 PNG, 접힌 장지갑 위에서 본 모습).

[요청] 홈 v2 — 기간·남은 금액과 접힌 지갑만 보이는 첫 화면, 탭하면 지갑이 열린다
1. 상단: 두 줄 배치. 1줄 "이번 달" 또는 "이번 주"(설정의 주기, 작은 글자, 보조색), 2줄 남은 금액을 화면에서 가장 큰 숫자로(예: "₩442,000 남음" — 숫자는 displayLarge 급, "남음"은 작게). 남은 금액 = 지갑 + 손. 그 아래 아주 작은 보조선 하나: "11.1 – 11.30 · 26일 남음".
2. 중앙: 접힌 지갑 이미지(가로 86%). 두께 표현: 지폐 장수에 비례해 지갑 아래쪽에 옆면 레이어를 1~6겹(장수 0→0겹, 1~5→1겹 … 26장 이상→6겹) 2~3dp 간격으로 어둡게 겹쳐 그려 두툼해 보이게. 지갑 위에 작은 배지: 확인 필요한 결제가 있으면 "확인 N" (탭하면 기존 확인 시트), 손에 든 돈이 있으면 "손에 ₩x".
3. 지갑 탭 → 열기 전환: 지갑이 살짝 커지며(1.0→1.06) 덮개가 위로 젖혀지는 느낌(graphicsLayer rotationX 0→-70°, cameraDistance 크게, transformOrigin 위쪽) 300~400ms, 동시에 열린 지갑 화면으로 크로스페이드. Haptics.tap() 호출. 뒤로 오면 반대 방향 짧게.
4. 지갑이 비었을 때(지폐·동전 0): 지갑 아래 큰 버튼 "용돈 넣기"(기존 ReceiveAllowance 로). 비어 있지 않으면 이 버튼은 숨기고 메뉴에만 둔다.
5. 오른쪽 위 메뉴(⋯ 아이콘 → DropdownMenu): 용돈 받기, 환전, 직접 기록, 가계부, 설정. 하단 NavigationBar 는 제거한다. 가계부·설정 화면은 Screen 으로 푸시되고 뒤로가기로 돌아온다(기존 BackHandler 유지). 기존 디버그 진입(설정 → 디버그, platformDebugEntries)은 그대로.
6. 기존 홈의 손에 든 돈 카드·권종 스택 그리드·정산 완료 카드는 홈에서 제거한다(정산 완료는 스낵바 한 줄로 대체). 손에 든 돈·스택은 열린 지갑 화면 몫이다.
7. 스크린샷: 기존 a/b/c/g/m/o 장면을 새 홈으로 갱신하고, (r) 지갑이 두툼한 상태(지폐 30장) 와 (s) 메뉴 열린 상태를 추가한다.

[완료 기준] ./gradlew :shared:ui:jvmTest 통과. 홈에 보이는 텍스트가 기간·남은 금액·보조선·배지뿐이다. 하단 탭이 없다. 지갑 탭으로 Screen.WalletOpen 에 들어가고 뒤로가기로 돌아온다. 기존 기능(용돈·환전·직접 기록·가계부·설정·확인 시트·시뮬레이터)이 메뉴를 통해 전부 도달 가능하다.
