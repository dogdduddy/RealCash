[요청] 열린 지갑 v4 — 권종 머리 간격 24dp, 동전은 오른쪽 세로 한 줄
1. WalletOpening.HEAD_STEP 을 14dp → 24dp 로. 오만원·만원·오천원의 보이는 머리 띠가 24dp 가 되고 천원은 30dp 더 아래에서 시작한다. 집기 히트 띠도 24dp(+±8dp 여유). 머리 띠가 넓어진 만큼 지폐 길이가 화면 아래를 넘지 않게 길이 상한 식을 다시 맞춘다(동전이 뭉치 아래에서 빠지므로 그 예약 높이는 없앤다).
2. 동전 초기 배치: 화면 오른쪽 가장자리에 세로 한 줄. 열의 중심 x = 화면 폭 − 12dp − 지름/2(가장 큰 동전 기준), 지폐 뭉치의 위쪽 끝(오만원 머리 top)에서 시작해 아래로 6dp 간격, 각 동전은 x 에 ±3dp 의 시드 기반 흔들림과 개별 회전. 동전 열은 지폐가 빠져나온 영역(입구 x ~ 가장 넓은 천원의 오른쪽 끝 + 6dp)과 겹치지 않아야 한다: 겹치면 지폐 길이(빠져나온 폭)를 줄여 맞춘다. 한 줄에 다 안 들어가면 그 왼쪽에 두 번째 줄(지폐 영역과 겹치지 않을 때만), 그래도 남으면 지금의 "+N" 넘침 버튼.
3. 바닥 drop 동작(어디든 놓으면 머묾, 지갑·접시·다른 동전 위 금지, 접시 ↔ 바닥 복귀)은 그대로. layout.coins 는 "오른쪽 세로 띠" 영역으로 바꾸고, 바닥 전체는 지금처럼 머리글 아래 화면 전체.
4. 세로 390×844, 320×568, 가로 844×390 에서 지갑·지폐·동전 열이 화면 안에 들어가고 서로 겹치지 않는다.
