[요청] 홈 닫힌 지갑을 새 그림으로 바꾸고 두께 레이어 제거

2. 지폐 수·배지 유무와 무관하게 지갑의 위치와 크기가 같다(지폐 0장과 30장 스크린샷에서 지갑 윤곽 좌표가 동일).
