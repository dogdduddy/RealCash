[목적] 검수를 통과한 실물풍 지폐 이미지 4종(오만원·만원·오천원·천원)을 지갑·꺼내기·환전 화면에 연결해, 지금의 Canvas 플레이스홀더 대신 "진짜 돈을 쓰는 느낌"이 나게 한다. 이 앱의 핵심 가치는 지폐를 보고·꺼내고·거슬러 받는 감각이므로, 이미지 연결의 완성도가 제품 인상을 결정한다.

[화면·파일] shared/ui 안에서만 작업한다.
- money/MoneyArt.kt — `MoneyArt` 인터페이스와 `LocalMoneyArt`(기본 None)가 이미 있다. 여기에 리소스 기반 구현을 추가한다.
- money/MoneyFaces.kt — `BillFace(denomination, modifier, painter: Painter?)`, `BillStack`, `UnitChip`, `CoinFace/CoinStack`.
- RealCashApp.kt — `RealCashRoot` 에서 `CompositionLocalProvider(LocalMoneyArt provides …)` 로 공급한다.
- 사용처: wallet/WalletHomeScreen.kt, takeout/TakeOutScreen.kt(드래그 고스트 포함), exchange/ExchangeScreen.kt, allowance/ReceiveAllowanceScreen.kt(스테퍼 행 아이콘이 있으면), confirm 시트의 거스름돈 칩.
- 리소스: Compose Multiplatform resources 가 이미 설정되어 있다(assets/img 가 customDirectory). 생성된 접근자는 `com.jim.realcash.ui.resources.Res.drawable.bill_w50000`, `bill_w10000`, `bill_w5000`, `bill_w1000` (내부 클래스, 같은 모듈에서 import 해서 쓴다). `bill_w10000_a` 는 미채택 시안이므로 쓰지 않는다. 이미지 크기: 1024x452 / 1024x470 / 1024x490 / 1024x512 (실물 비율 154:68, 148:68, 142:68, 136:68). 투명 PNG, 지폐 바깥은 투명.

[요청] 실물풍 지폐 이미지 4종을 지갑·꺼내기·환전 화면에 연결
1. `ResourceMoneyArt : MoneyArt` 를 만들어 `painter(denomination)` 이 권종별 `painterResource(Res.drawable.bill_wNNNN)` 을 돌려주게 한다(동전은 null 유지). `RealCashRoot` 에서 `LocalMoneyArt provides ResourceMoneyArt` 로 공급한다. 데스크톱·iOS·Android 공통이어야 한다.
2. `BillFace` 는 painter 가 있으면 Canvas 플레이스홀더 대신 이미지를 그린다: `ContentScale.Fit`, 권종별 실제 비율 유지(오만원이 가장 길고 천원이 가장 짧다 — 스택 너비가 실물처럼 조금씩 달라지게 `relativeSize` 를 비율에서 계산), 모서리는 이미지 자체에 있으므로 추가 clip 은 아주 약하게(2dp 이하)만, 지폐 아래 부드러운 그림자(elevation 2~3dp 느낌).
3. `BillStack` 의 뒤쪽 레이어(겹친 장수 표현)도 같은 이미지를 쓰되 살짝 어둡게(알파 또는 틴트)하고 오프셋은 기존 값 유지. 장수 배지는 그대로.
4. `UnitChip`(손에 든 돈·거스름돈·트레이 칩)은 지폐 이미지를 작은 썸네일(높이 20~24dp)로 쓴다. 숫자 라벨은 유지.
5. 꺼내기 화면의 드래그 고스트는 이미지를 쓰고 약간 기울임(2~4도)과 그림자를 더해 "집어 든" 느낌을 준다. 기존 graphicsLayer 지연 읽기 성능 패턴은 그대로.
6. 다크 테마에서는 이미지를 약간만 어둡게(알파 0.92 정도)하고 종이색 배경과 충돌하지 않게 카드 배경을 확인한다.
7. 동전은 기존 Canvas 유지(이미지는 아직 없다).
8. 스크린샷 테스트: 기존 ScreenshotTest 의 지갑(b, c, g)·꺼내기(h, i)·환전(j) 장면이 실제 이미지로 렌더링되게 하고, 새 장면 (m) 지갑 홈에 네 권종이 모두 있는 상태를 추가한다. 이미지 로딩은 `painterResource` 가 동기적으로 동작하는 데스크톱 테스트에서 그대로 되어야 하며, 안 되면 `ImageComposeScene` 에서 프레임을 몇 번 더 진행시킨다.
